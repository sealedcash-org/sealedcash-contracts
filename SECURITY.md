# Security policy

SealedCash contracts can hold value. Treat every report as sensitive and do
not disclose an exploitable issue publicly before a coordinated fix.

Report vulnerabilities to **support@sealedcash.com** with the repository,
affected commit, reproduction steps, and impact. Do not include private keys,
user secrets, or live account data.

This repository is not an audit, warranty, or statement that any deployment is
production-ready. Never send funds to an address copied from an issue, test,
log, or unverified release artifact.
